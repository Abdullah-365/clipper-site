Privacy Policy

Last updated: 18 November 2026

What Clipper is

Clipper is a personal automation tool run by a single operator on their own computer. It uploads short video clips to the operator's own YouTube channel using the YouTube API Services. It does not offer sign-in to the public.

YouTube API Services

Clipper uses YouTube API Services. By using Clipper you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed and how it is used

  • OAuth token for the operator's Google account, used only to upload videos and read basic channel information (channel name) for that same account.
  • Video metadata Clipper itself creates (titles, descriptions, tags) and the IDs/links of uploaded videos, used to keep a log of what was posted.

Clipper does not access, collect or store data about any other YouTube users, viewers or commenters.

Storage and sharing

All data is stored locally on the operator's computer. Nothing is sold, shared with third parties, or used for advertising. Uploaded videos are, of course, sent to YouTube.

Retention and deletion

The OAuth token is kept until access is revoked. Local logs can be deleted at any time. Access can be revoked at any time at Google security settings → Third-party apps, which immediately stops Clipper from uploading.

Cookies

This website uses no cookies or tracking. Clipper itself does not place cookies on any device.
